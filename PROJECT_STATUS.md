This does NOT affect the actual freshness *gating* used by `classify_recommendation()` (Gate 2), which correctly uses each quote's real `lastUpdatedAt`/`observation_time` regardless of cache status (verified 2026-08-20) — `captured_at` is purely a storage/display field for `player_prop_odds` snapshot history, not consumed by any staleness decision
- Alt lines are preserved but not scanned by default (only main lines appear in output)
- NFL/WNBA scheduling is deployed and running in production (`c141475`, 2026-08-20) — `THE_ODDS_API_KEY` is set on both `mlb-vip-worker` and `mlb-vip-dashboard` in Render (the dashboard needed its own copy too — see the 2026-08-21 Multi-League Health entry above for the real bug that surfaced when it was missing there).
- The Odds API account was upgraded 2026-08-22 to the paid "20K" tier (20,000 credits/month, $30/mo) — shared across WNBA's existing usage and the new MLB/NFL quota-exhaustion fallback (see the 2026-08-22 entry above). `DEFAULT_MONTHLY_BUDGET` in `src/odds_api_credits.py` reflects this real tier and is env-configurable (`THE_ODDS_API_MONTHLY_BUDGET`) if it changes again. Player-prop credits remain the real constraint on a sustained WNBA props cadence even at the larger budget — see `docs/MARKET_CAPABILITY.md` for the live-verified per-call costs.
