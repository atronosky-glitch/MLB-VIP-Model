## Bugs Found and Fixed

1. **Python `bool` subclass of `int`**: `isinstance(False, int)` returns `True`, causing `MLB_BACKUP_COMPRESSION=true` to fail `int()` conversion. Fixed by checking `bool` before `int` in type coercion priority.

2. **SQLite backup filename collision**: Two backups created in the same second got identical filenames (second-precision timestamps). Fixed by using microsecond-precision (`%Y%m%d_%H%M%S_%f`).

3. **`analyze_calibration()` type mismatch**: Job handler passed `config.database_path` (string) to `analyze_calibration()` which expects `sqlite3.Connection`. Fixed by opening connection in handler.

4. **Google Sheets early-return ordering**: `export_recommendations()` checked credentials before checking for empty recs, causing `FileNotFoundError` when called with empty DB and missing credentials. Moved no-recs check before credential validation.
